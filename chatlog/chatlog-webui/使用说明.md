# 微信聊天记录分析系统 - 超简单使用指南

## 🚀 一键启动（推荐）

```bash
./一键启动.sh
```

就这么简单！脚本会自动：
- 下载安装 chatlog 工具
- 启动微信（如果未运行）
- 获取微信密钥并解密数据
- 启动所有服务
- 打开浏览器

## 📱 登录信息

- **网址**: http://localhost:3001
- **用户名**: `admin`
- **密码**: `Admin123@`

## ⚡ 快速故障排除

### 问题1: 权限错误
**解决**：在系统偏好设置 → 安全性与隐私 → 隐私 → 完全磁盘访问权限中添加"终端"

### 问题2: 微信数据获取失败
**解决**：
1. 确保微信已登录
2. 重启微信后再试

### 问题3: 网络错误
**解决**：等待10秒再刷新浏览器

## 🎯 功能使用

1. **登录后** → 点击"聊天搜索"
2. **搜索消息** → 输入关键词搜索
3. **AI分析** → 选择分析类型，获得智能洞察

## 🛑 停止服务

在终端按 `Ctrl+C` 即可停止所有服务

**需要帮助？** 检查终端输出信息，所有状态都会实时显示。
