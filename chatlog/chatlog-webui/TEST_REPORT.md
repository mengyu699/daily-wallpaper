## 修复过程

### 1. 问题诊断

**发现的问题**：
- Chatlog API调用参数格式错误
- 消息解析函数无法正确处理chatlog返回的数据格式
- 导出功能API路径错误

**根本原因**：
- 缺少必需的`time`参数导致API调用失败
- 解析函数期望CSV格式但实际返回特殊文本格式
- 错误的fallback机制导致总是返回模拟数据

### 2. 核心修复

**API调用修复**：
```javascript
// 修复前：缺少time参数
params.talker = contact;
params.limit = 50;

// 修复后：添加必需的time参数
params.talker = contact;
params.time = new Date().toISOString().split('T')[0];
params.limit = 50;
```

**数据解析修复**：
```javascript
// 修复前：错误的CSV解析
const parts = line.split(',');

// 修复后：正确的chatlog格式解析
const senderTimeMatch = line.match(/^(.+?)\((.+?)\)\s+(.+)$/);
if (senderTimeMatch) {
    const [, senderName, senderId, timeStr] = senderTimeMatch;
    // 获取下一行作为消息内容
    content = lines[i + 1].trim();
}
```
