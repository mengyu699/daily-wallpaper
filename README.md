# 每日壁纸生成器 Daily Wallpaper Generator

一个简单优雅的 iPhone 壁纸生成工具，让你的目标每天陪伴着你。

## 🌟 特性

- 📱 专为 iPhone 16 Pro (1206×2622px) 优化
- ✏️ 支持自定义文字内容
- 🎨 5种精选渐变背景
- 🌈 自定义文字颜色
- 📏 4种行间距预设
- 💾 一键下载高清壁纸
- 📅 自动添加日期水印

## 🚀 在线使用

访问: [在线体验地址](https://你的用户名.github.io/仓库名/)

或者下载 `index.html` 到本地直接打开使用。

## 📱 使用方法

1. 输入你的今日目标或激励文字
2. 选择喜欢的背景风格
3. 调整文字颜色和行间距
4. 点击下载按钮保存壁纸
5. 在 iPhone 设置中更换壁纸
